# cricket-score-tracker
🏏 Cricket Score Tracker

A simple Cricket Score Tracker made using Python.

📌 About

This project is a beginner-friendly Python program that helps track cricket scores and player runs.

🛠️ Python Concepts Used

- Variables
- User Input
- Dictionaries
- Lists
- Loops
- Conditional Statements
- Basic Calculations

▶️ How to Run

python cricket_score_tracker.py

🎯 Purpose

This project was created to practice Python programming concepts by building a simple real-world application based on cricket.
